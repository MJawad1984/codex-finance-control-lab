# Codex-assisted build provenance

## What happened

This initial version was built on **1 November 2026** during Muhammad Jawad's ChatGPT Work/Codex session, after he asked to populate the public GitHub repository for a Codex Ambassador application.

The user supplied the domain direction: a finance-control invoice-reconciliation lab, deterministic financial calculations, explicit rules, synthetic data, reconciliation controls, duplicate handling, testing, CI and reproducible learning. Codex produced the Python implementation, synthetic fixtures, tests, documentation and workflow, then executed checks and corrected implementation/formatting issues before publication.

The repo was empty at takeover. A historical handoff mentioned an earlier build ZIP, approximate file/test counts and a CI matrix; that ZIP could not be located in the available Library/context. **This version is a new implementation, not a recovery of that earlier package.** No earlier development history, passing tests or commits have been invented.

## What Codex does and does not do

Codex helps translate domain requirements into code, tests, review questions and documentation. The application runtime performs exact integer calculations and explicit deterministic classification. No LLM API participates in amount calculation, matching, exception approval or accounting conclusions. No API key is needed.

The maintainer is a finance-domain professional building coding capability with AI assistance, not presented as a conventional software engineer. This repository does not claim production deployment, confidential employer implementation or independent professional assurance.

## Review and limitations

The same coding assistant wrote and reviewed the implementation and tests. Passing those tests is useful evidence, not independent assurance. The small worked reference in CONTROL_DESIGN.md was calculated directly from displayed sample amounts and checked separately from the engine. There has been no independent human code audit, production security review, performance qualification or user-acceptance signoff.

No exact underlying model ID, full model-call trace or unavailable earlier session log is asserted. Git history captures this published implementation. For future edits, record the requirement, failing case, change and check result in a reviewable commit or pull request.
